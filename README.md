# Sirius Vardiya Yönetimi

## Streamlit Cloud yayınlama

1. Bu klasördeki dosyaları GitHub deponuza yükleyin.
2. `share.streamlit.io` adresine GitHub ile giriş yapın.
3. Create app seçin.
4. Repository ve `app.py` dosyasını seçin.
5. Deploy düğmesine basın.

Yerel çalıştırma: `pip install -r requirements.txt` ardından `streamlit run app.py`.
